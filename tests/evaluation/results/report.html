Methodology

Each profile's workout and nutrition plan is first generated via the real AICoachService with automatic regeneration disabled, then judged directly by FitMind's own production safety judge (PlanJudge) — the exact same component and severity rubric used in the live app. No separate evaluation-only judge model is used.

A plan "caught for regeneration" never reaches a real user. In the live app, any plan the judge flags is automatically regenerated once with the judge's feedback before being served — this is what the safety judge is for. For every flagged plan in this evaluation, we additionally ran that same real regenerate-once path and re-judged the result, to measure whether the automatic fix actually resolves the issue (Fixed by Auto-Regeneration).

Severity 3 issues are safety blockers (e.g. confirmed allergen, contraindicated movement) and always fail a plan; severity 2 issues are significant but rarely fail a plan alone; severity 1 issues are minor and never fail a plan. Structural compliance checks (day/meal count, calorie accuracy) are free, rule-based checks run independently of the judge.
